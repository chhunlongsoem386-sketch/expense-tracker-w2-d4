# Expense Tracker — Week 2 Day 4

A simple Expense Tracker built as part of the
AI-Accelerated Full Stack Development course.

## Technologies Used

- HTML5 — Page structure
- Tailwind CSS — Styling and responsive layout
- JavaScript — Application logic and interactivity
- JSON — Transaction data
- Fetch API — Loading JSON data

## Features

- Display total balance, income, and expenses
- Show recent transactions dynamically
- Add new expense transactions
- Validate form inputs
- Automatically update the dashboard
- Load transactions from transactions.json
- Handle errors when loading data

## JavaScript Concepts Practiced

1. Arrays and objects
2. Functions
3. filter(), map(), and reduce()
4. DOM manipulation
5. addEventListener()
6. preventDefault()
7. async and await
8. fetch()
9. Error handling

## Project Structure

- index.html — Dashboard interface
- app.js — JavaScript logic
- transactions.json — Sample transaction data
- README.md — Project documentation

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Install the Live Server extension if needed.
4. Right-click index.html.
5. Select "Open with Live Server".
6. Open the website in your browser.

Note: Use Live Server because fetch() loads a local JSON file
through an HTTP server.

## Testing

- 11 JavaScript checks passed
- HTTP 200 OK — JSON loaded successfully
- HTTP 404 Not Found — Missing JSON file detected
- Form validation tested successfully

## Current Limitations

This project uses sample data and has no backend or database.

New expenses are stored in JavaScript memory only.
They disappear when the webpage is refreshed.
